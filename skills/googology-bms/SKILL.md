# Bashicu Matrix System 展开器

## 概述

本技能基于 BM4（Bashicu Matrix 第 4 版）规则，对给定的 BMS 矩阵求其第 n 个基本列。
输入矩阵必须是合法的 BMS 序列，输出为展开后的矩阵字符串。

## 输入格式

矩阵以连续括号列表示，形如：

    (a1,a2,...,ak)(b1,b2,...,bk)...

- 每一对括号代表矩阵的**一列**，括号内逗号分隔的是该列的**各行**。
- 列与列之间**不能有空格**。

### 自动补齐

输入矩阵的各列**不要求行数一致**，省略的末尾 0 会被自动补全。
例如输入 `(0)(1,1)` 会被视为 `(0,0)(1,1)`，
输入 `(0)(1,1,1,1)(2,1)(1,1,1)` 会被视为 `(0,0,0,0)(1,1,1,1)(2,1,0,0)(1,1,1,0)`。

因此你可以直接使用用户原始输入，无需自行补齐列。

## 调用方式

    node --jitless <this-skill-directory>/scripts/BM.js "<matrix>" <n>

### 参数

| 参数 | 类型 | 必填 | 说明 |
|:---|:---|:---|:---|
| `matrix` | string | 是 | BMS 矩阵，形如 `(0,0)(1,1)(2,2)` |
| `n` | integer | 是 | 基本列编号，从 0 开始计；`n=0` 表示取第 0 个基本列 |

## 示例

输入：

    node --jitless <this-skill-directory>/scripts/BM.js "(0,0)(1,1)(2,2)" 4

输出：

    矩阵为极限序数，其基本列第 4 项为 (0,0)(1,1)(2,1)(3,1)(4,1)(5,1)

## 错误处理

- 若矩阵格式非法，脚本会向 stderr 输出错误信息并以非零退出码结束。
- 此时应向用户说明“矩阵格式无效”，并提示正确格式，不要直接粘贴原始报错。
- 若矩阵中某一列含有非数字项，脚本会拒绝执行并提示格式错误。

## 输出

脚本输出的是一句自然语言描述，可能出现三种形态：

- `矩阵为 0`
- `矩阵为极限序数，其基本列第 n 项为 (0,0)(1,1)(2,1)...`
- `矩阵为后继序数，其前驱为 (0,0)(1,1)`

Agent 应把整句直接回给用户，不要额外解析或改写。

## 技术备注

- 展开规则基于 BM4。
- 对于列数较多或行数较深的矩阵，展开结果可能非常长，建议在输出前判断长度，必要时截断或提示用户。
